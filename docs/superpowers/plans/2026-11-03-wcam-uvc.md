# wcam H.264 UVC Implementation Plan

> Execute in the existing `wcam` worktree, task by task, with
> superpowers:executing-plans and superpowers:test-driven-development.

**Goal:** Sensor-free FHD color bars with a centered frame counter over H.264 UVC.

**Architecture:** One producer task owns the NV12 and encoded buffers. The
native encoder consumes NV12; the SDK UVC device queues encoded access units.
USB completion must return ownership before the encoded buffer is reused.

**Tech Stack:** C, FreeRTOS, Realtek hardware H.264 and USB device libraries.

**Spec:** ../specs/2026-11-03-wcam-uvc.md

## Global constraints

- 1920x1080, NV12, centered incrementing frame counter; no sensor stream.
- No customer `.a`; retain provenance for restored vendor USB library.
- Sequential clean, LP `-j1 -B`, then IS `-j8`; external Realtek GCC 6.4.1.

## Review focus

- Counter rollover and shorter text must erase old glyphs; test pixel output.
- NV12 UV order and buffer size must be correct; test colors and guard bytes.
- USB probe/commit must agree with descriptors, including GET_MIN/MAX/DEF.
- Stop/disconnect must not release a buffer still owned by USB DMA.
- Encoder clocks, cache maintenance and initial SPS/PPS must work without ISP.
