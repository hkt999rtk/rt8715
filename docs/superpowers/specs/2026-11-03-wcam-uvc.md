# wcam H.264 UVC POC

Generate 1280x720 NV12 color bars in memory, overlay a centered decimal
frame counter, encode with the SDK hardware H.264 encoder and stream over USB
as a UVC device. No image sensor input and no customer archives.

POC defaults: 30 fps, 2 Mbit/s CBR, one IDR per second; advertise only this
H.264 frame-based format and resolution. Counter starts at zero on boot and
advances per generated frame. Force an IDR when host streaming starts.

Use native Realtek libraries. The missing original USB library is available in
the local July SDK backup. Keep its provenance and analysis evidence.

Deliver firmware, source, reproducible build instructions and host validation
steps. Compilation and host tests do not establish USB enumeration, hardware
encoding or sustained frame rate; those require a board.
