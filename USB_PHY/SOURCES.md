**閱讀重點與適用範圍**

- **R01**：usb_cal_data[]、usb_chip_get_cal_data()、usb_chip_init()。 官方原始碼；AmebaSmart 基準設定表，不代表 RTL8195B 的寄存器定義。
- **R02**：usb_cal_data_t 的 page/addr/val。 官方原始碼；page/addr/val 的結構定義。
- **R03**：SEC_OTP_SYSCFG2／3；只代表 Smart 定義，不是 E6/F0 位元表。 官方原始碼；校準參數種類，不能直接換算 E6/F0。
- **R04**：Device Tree 中 realtek,otg-phy 與校準表。 官方文件；DTS PHY 校準表及 DWC controller 分離。
- **R05**：硬體抽象層 API／PHY 校準備註。 官方文件；USB 初始化與 PHY 校準說明。
- **D01**：搜尋 DWC2_CORE_REV_3_10a。 原始碼；0x4f54310a 對應 DWC2 3.10a。下載內容為 Gitiles base64，檔案保存解碼後原始碼。
- **D02**：offset 0x34；vendor access 欄位。本次僅有線上索引核對及本地 header 佐證。 官方寄存器文件；跨 SoC 比較 controller vendor access，不是 Realtek PHY 位元表。
- **S01**：第 2 節 UTMI 連接、第 3 節 reset；另有離線 HTML 與五張原圖。 官方整合說明；controller/PHY、UTMI 與 reset 時序。
- **S02**：不同 PHY 系列、製程及板級調整。 官方產品資料；PHY 有不同系列、製程與校準需求。
- **S03**：femtoPHY 產品資料，不能辨識本案 PHY。 官方產品資料；不能證明本專案使用 femtoPHY。
- **S04**：只保存文件索引；未下載需登入／授權的完整 databook 或 programming guide。 官方文件入口；保存索引頁，未取得需登入授權的完整 databook。
- **K01**：V1.1 / 2019-01-09；30 頁。第 2.2 節、表 2-7；第 4.2／4.3 節。 Rockchip 撰寫的原始技術文件，下載主機為第三方鏡像；詳見文件內版本頁。 文件封面標註「内部资料」，本次取得的是公開鏡像，非 Rockchip 官網下載。
- **K02**：與 K01 同一文件的 HTML 鏡像，不是獨立來源；已取得 PDF。 同一 Rockchip 文件的鏡像 HTML，方便全文搜尋，不是獨立交叉驗證來源。
- **T01**：第 3.2 節 USB2PHY tuning；本次未取得完整頁面，替代原始證據見 T02。 官方應用文件；以 STM32MP 系列為例，不能移植位元值至 Realtek。
- **N01**：Rev.1.1 / 2023-12-01；48 頁。表 20 / PDF 第 21 頁。 官方 datasheet；disconnect/squelch/termination 的可調範例，不是 Synopsys macro 身分證據。
- **N02**：[PATCH v4 5/6]，2023-05-16；fake disconnection 修正動機。 NXP 作者提交的原始 patch 郵件，由 LKML 鏡像保存；僅作設計案例，非最終 upstream ABI。
- **T02**：COMPDISTUNE／SQRXTUNE mask 與 device tree property 解析。 ST 官方原始碼；補充 T01 網頁離線副本取得失敗的證據缺口。branch 會移動，內容以 SHA-256 為準。

**資料保存方式**

原始 PDF／HTML／原始碼內容以下載後 bytes 保存；D01 為 Gitiles base64 解碼後的原始碼。另附的 `.txt` 是供搜尋的自動抽取文字，圖表和欄位順序以原件為準。`nanophy_to_otg.offline.html` 是衍生閱讀版，改用本地附圖並移除網站腳本／外部樣式，原始 HTML 另行保留。

K01 是 Rockchip 撰寫、第三方網站提供的 PDF，封面標示「内部资料」；本次未取得 Rockchip 官網版本，不能把鏡像等同官方下載管道。N02 是原作者 patch 的郵件鏡像。其他已下載文件／原始碼由各廠官方站或官方原始碼倉庫取得；D01 是 Google 維護的 kernel 原始碼倉庫。
